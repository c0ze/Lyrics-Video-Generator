# The Recursion of Ash and Lightning — Music Video Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a cinematic 5:48 lyric music video for *The Recursion of Ash and Lightning* (The Seventh Shadow — Anti-Nativity): 25 interchanging AI-painted scenes, character-referenced, animated in Remotion with escalating glitch effects, synced lyrics, rendered to 1080p60 H.264 with AAC-384k/48k audio encoded from the WAV master.

**Architecture:** A self-contained `src/AntiNativity/` Remotion project with a bespoke scene-based composition (NOT the static `lyricVideo/Composition`). Scene paintings are generated by `scripts/generate-antinativity.mjs` (Gemini flash-image, reference-conditioned on the two character portraits) into `public/AntiNativity/scenes/`. The composition reads a `scenes.json` storyboard + the voice-tagged `.lrc`, drives a scene track with per-scene motion/grade/transition and a library of procedural effect components, and overlays voice-tinted lyrics. Registered via an isolated block in `Root.tsx` (own props type — does not perturb the shared `LyricVideoProps`). Rendered through the existing `render-track.sh` (extended with optional audio bitrate/rate).

**Tech Stack:** Remotion 4.0.434, React 19, TypeScript, `@google/genai` (Gemini image + optional Veo), `sharp` (hi-res post-process), `@remotion/google-fonts` (Cinzel, Cormorant Garamond), ffmpeg/ffprobe.

**Verification model:** This repo has no unit-test runner (only `eslint`+`tsc`). Pure logic (voice parser, scene timing, model resolver) is verified with Node's built-in `node:test` on `.mjs` mirrors where cheap; everything visual is verified in Remotion Studio at named frames; the final file is verified with `ffprobe` assertions. No vitest is added (YAGNI).

- [ ] **Step 2: Write the voice parser (pure function over `parseLrc`)**

`src/AntiNativity/lyrics.ts`:
```ts
import { parseLrc } from "../lyricVideo/lyrics";
import type { Voice, VoicedLine } from "./types";

const VOICE_MAP: Record<string, Voice> = {
  male: "talciron",
  female: "ophelia",
  duet: "duet",
  both: "duet",
};

/** parseLrc leaves a leading "[male] " / "[female] " / "[duet] " tag in the text. Split it out. */
export const splitVoice = (raw: string): { voice: Voice; text: string } => {
  const m = raw.match(/^\s*\[(male|female|duet|both)\]\s*(.*)$/i);
  if (!m) return { voice: "duet", text: raw.trim() };
  return { voice: VOICE_MAP[m[1].toLowerCase()], text: m[2].trim() };
};

export const parseVoicedLyrics = (lrc: string, fps: number): VoicedLine[] =>
  parseLrc(lrc, fps).map((l) => {
    const { voice, text } = splitVoice(l.text);
    return { startFrame: l.startFrame, voice, text };
  });
```

```js
test("maps duet", () => {
  assert.equal(splitVoice("[duet] Nay, sweet architect").voice, "duet");
});

  assert.deepEqual(splitVoice("  no tag here "), { voice: "duet", text: "no tag here" });
});
```

`scripts/resolve-image-model.mjs`:
```js
// Resolve the newest available Gemini flash-image model id.
// Honors IMAGE_MODEL if set; otherwise tries candidates in order until one returns an image.
export const IMAGE_MODEL_CANDIDATES = [
  "gemini-3.5-flash-image",
  "gemini-3-flash-image",
  "gemini-3-pro-image-preview",
  "gemini-2.5-flash-image",
];

/** Returns the first candidate that produces an image, or throws. `tryModel(id)` => boolean. */
export async function resolveImageModel(tryModel, { envModel = process.env.IMAGE_MODEL } = {}) {
  const order = envModel ? [envModel, ...IMAGE_MODEL_CANDIDATES] : IMAGE_MODEL_CANDIDATES;
  const seen = new Set();
  for (const id of order) {
    if (seen.has(id)) continue;
    seen.add(id);
    try {
      if (await tryModel(id)) return id;
    } catch (err) {
      const msg = String(err?.message || err);
      if (!/not.?found|unsupported|invalid|permission|model/i.test(msg)) throw err;
    }
  }
  throw new Error("No usable image model. Tried: " + order.join(", "));
}
```

## Task 6: Scene image generator

**Files:** Create `scripts/generate-antinativity.mjs`

- [ ] **Step 1: Write the generator**

`scripts/generate-antinativity.mjs`:
```js
/* Generate Anti-Nativity scene paintings with Gemini flash-image, reference-conditioned
 * on the two character portraits. Hi-res 16:9, idempotent, records a manifest.
 *
 * Run (source the landing-page .env for GEMINI_API_KEY):
 *   set -a; . "$HOME/projects/anti-nativity.arda.tr/.env"; set +a; \
 *     node scripts/generate-antinativity.mjs                 # all missing
 *   ... node scripts/generate-antinativity.mjs --only S1,S3,S6   # subset
 *   ... node scripts/generate-antinativity.mjs --force           # regenerate
 * Env: GEMINI_API_KEY (required), IMAGE_MODEL (optional override).
 */
import fs from "node:fs";
import path from "node:path";
import { fileURLToPath } from "node:url";
import { GoogleGenAI } from "@google/genai";
import sharp from "sharp";
import { resolveImageModel } from "./resolve-image-model.mjs";

const ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), "..");
const KEY = process.env.GEMINI_API_KEY;
if (!KEY) {
  console.error('GEMINI_API_KEY not set. Run: set -a; . "$HOME/projects/anti-nativity.arda.tr/.env"; set +a; node scripts/generate-antinativity.mjs');
  process.exit(1);
}
const args = process.argv.slice(2);
const getArg = (n) => { const i = args.indexOf(n); return i >= 0 ? args[i + 1] : undefined; };
const only = getArg("--only")?.split(",").map((s) => s.trim());
const force = args.includes("--force");
const songId = getArg("--song") || "recursion";
const TARGET_W = 2304, TARGET_H = 1296; // 16:9, ~1.2x of 1080p for push-in headroom

const scenes = JSON.parse(fs.readFileSync(path.join(ROOT, "src/AntiNativity/scenes.json"), "utf8"));
const song = scenes.songs[songId];
const outDir = path.join(ROOT, "public/AntiNativity/scenes", songId);
fs.mkdirSync(outDir, { recursive: true });
const manifestPath = path.join(ROOT, "src/AntiNativity/scenes.manifest.json");
const manifest = fs.existsSync(manifestPath) ? JSON.parse(fs.readFileSync(manifestPath, "utf8")) : {};

const ai = new GoogleGenAI({ apiKey: KEY });
const sleep = (ms) => new Promise((r) => setTimeout(r, ms));
const refPart = (relPath) => ({
  inlineData: { mimeType: "image/jpeg", data: fs.readFileSync(path.join(ROOT, relPath)).toString("base64") },
});

function buildPrompt(scene) {
  const palette = song.palettes[scene.temp];
  const charDir = scene.who.map((w) => scenes.characterDirections[w]).join(" ");
  return [
    scenes.style,
    `Palette: ${palette}.`,
    `Scene: ${scene.prompt}`,
    charDir,
    "Composition: wide cinematic 16:9, generous negative space, single coherent image.",
    `Avoid: ${scenes.negative}.`,
  ].filter(Boolean).join(" ");
}

function imageFromResponse(res) {
  const parts = res?.candidates?.[0]?.content?.parts || [];
  const img = parts.find((p) => p.inlineData?.data);
  if (!img) {
    const txt = parts.find((p) => p.text);
    throw new Error("no image in response" + (txt ? "; text: " + txt.text.slice(0, 160) : ""));
  }
  return Buffer.from(img.inlineData.data, "base64");
}

async function generateOnce(model, scene) {
  const parts = [{ text: buildPrompt(scene) }, ...scene.who.map((w) => refPart(scenes.refs[w]))];
  const res = await ai.models.generateContent({
    model,
    contents: [{ parts }],
    generationConfig: { responseModalities: ["IMAGE", "TEXT"] },
  });
  return imageFromResponse(res);
}

async function generateWithRetry(model, scene) {
  for (let attempt = 1; attempt <= 4; attempt++) {
    try { return await generateOnce(model, scene); }
    catch (err) {
      if (attempt === 4) throw err;
      const wait = 2 ** attempt * 1500;
      console.warn(`  ! ${scene.id} attempt ${attempt} failed (${String(err.message).slice(0, 120)}); retry in ${wait}ms`);
      await sleep(wait);
    }
  }
}

async function run() {
  const todo = song.scenes.filter((s) => (!only || only.includes(s.id)) &&
    (force || !fs.existsSync(path.join(outDir, `${s.id}.jpg`))));
  if (todo.length === 0) { console.log("Nothing to generate."); return; }

  // Resolve the model by generating the first scene; cache that buffer so no image is made twice.
  const probe = todo[0];
  let probeBuffer = null;
  const model = await resolveImageModel(async (id) => { probeBuffer = await generateOnce(id, probe); return true; });
  console.log("Using image model:", model);

  let made = 0;
  for (const scene of todo) {
    const outFile = path.join(outDir, `${scene.id}.jpg`);
    process.stdout.write(`• ${scene.id} (${scene.temp}, who=[${scene.who.join(",")}]) … `);
    const raw = scene.id === probe.id && probeBuffer ? probeBuffer : await generateWithRetry(model, scene);
    probeBuffer = null;
    await sharp(raw).resize(TARGET_W, TARGET_H, { fit: "cover", position: "centre" }).jpeg({ quality: 92 }).toFile(outFile);
    const { size } = fs.statSync(outFile);
    manifest[`${songId}/${scene.id}`] = { model, prompt: buildPrompt(scene), refs: scene.who, bytes: size, at: new Date().toISOString() };
    made++;
    console.log(`ok (${(size / 1024).toFixed(0)} KB)`);
  }
  fs.writeFileSync(manifestPath, JSON.stringify(manifest, null, 2) + "\n");
  console.log(`\nDone — ${made} generated. Model: ${model}.`);
}
run().catch((e) => { console.error("Fatal:", e.message); process.exit(1); });
```

Note: the model resolver generates the first scene to discover a working model; that buffer is
cached (`probeBuffer`) and reused for its write, so no image is generated twice.

```tsx
const kenBurns = (motion: SceneDef["motion"], p: number) => {
  switch (motion) {
    case "pull-back": return { s: lerp(1.22, 1.04, p), x: 0, y: 0 };
    case "pan-left": return { s: 1.14, x: lerp(3, -3, p), y: 0 };
    case "pan-right": return { s: 1.14, x: lerp(-3, 3, p), y: 0 };
    case "crane-up": return { s: 1.16, x: 0, y: lerp(4, -4, p) };
    case "tilt-up": return { s: 1.16, x: 0, y: lerp(5, -3, p) };
    case "fall": return { s: lerp(1.05, 1.3, p), x: 0, y: lerp(-4, 6, p) };
    case "orbit": return { s: 1.16, x: Math.sin(p * Math.PI) * 3, y: Math.cos(p * Math.PI) * 1.5 };
    case "push-in": default: return { s: lerp(1.05, 1.18, p), x: 0, y: 0 };
  }
};

export const AntiNativityComposition: React.FC<AntiNativityProps> = ({ songId, audioFile, lyricsText, bannerText }) => {
  const frame = useCurrentFrame();
  const { fps, durationInFrames } = useVideoConfig();
  const song = SCENES[songId];

  const [handle] = useState(() => delayRender("Anti-Nativity fonts"));
  useEffect(() => {
    Promise.all([cinzel.waitUntilDone(), cormorant.waitUntilDone(), cormorantItalic.waitUntilDone()])
      .then(() => continueRender(handle)).catch((e) => cancelRender(e));
  }, [handle]);

  const lines = useMemo(() => parseVoicedLyrics(lyricsText, fps), [lyricsText, fps]);
  const lineStarts = useMemo(() => lines.map((l) => l.startFrame), [lines]);

  const scenes = useMemo(() => {
    const withStart = song.scenes.map((s) => ({
      ...s,
      start: typeof s.startSec === "number" ? Math.round(s.startSec * fps) : lineStarts[s.startLineIndex ?? 0] ?? 0,
    }));
    return withStart.map((s, i) => ({ ...s, end: i < withStart.length - 1 ? withStart[i + 1].start : durationInFrames }));
  }, [song.scenes, lineStarts, fps, durationInFrames]);

  // active lyric line
  let ai = -1;
  for (let i = lineStarts.length - 1; i >= 0; i--) { if (frame >= lineStarts[i]) { ai = i; break; } }
  const firstLineStart = lineStarts[0] ?? 0;

  return (
    <AbsoluteFill style={{ backgroundColor: "#05070a" }}>
      <Audio src={staticFile(audioFile)} />

      {/* scene track */}
      {scenes.map((s, i) => {
        if (frame < s.start - CROSSFADE || frame >= s.end) return null;
        const p = (frame - s.start) / Math.max(s.end - s.start, 1);
        const kb = kenBurns(s.motion, p);
        const opacity = s.transition === "hard-cut"
          ? (frame >= s.start ? 1 : 0)
          : interpolate(frame, [s.start - CROSSFADE, s.start], [0, 1], { extrapolateLeft: "clamp", extrapolateRight: "clamp" });
        const painting = (
          <Img src={staticFile(`AntiNativity/scenes/${songId}/${s.id}.jpg`)}
            style={{ width: "100%", height: "100%", objectFit: "cover",
              transform: `scale(${kb.s}) translate(${kb.x}%, ${kb.y}%)`, filter: TEMP_GRADE[s.temp] }} />
        );
        const fx = new Set(s.effects);
        let layer: React.ReactNode = painting;
        if (fx.has("wireframe-reveal")) layer = <WireframeReveal reveal={Math.sin(p * Math.PI)}>{layer}</WireframeReveal>;
        if (fx.has("recursion-feedback")) layer = <RecursionFeedback progress={p} childrenNode={layer} />;
        if (fx.has("rgb-split")) layer = <RGBSplit amount={2 + (s.temp === "white" ? 8 : 4) * Math.sin(p * Math.PI)}>{layer}</RGBSplit>;
        if (fx.has("glitch") || fx.has("sixth-finger") || fx.has("multi-version")) {
          const intensity = s.id === "S20" ? clamp01(p * 1.2) : 0.35 + 0.25 * Math.sin(p * Math.PI);
          layer = <Glitch intensity={intensity}>{layer}</Glitch>;
        }
        return <AbsoluteFill key={s.id} style={{ opacity, overflow: "hidden" }}>{layer}</AbsoluteFill>;
      })}

      {/* atmosphere driven by the active scene's temperature */}
      {(() => {
        const cur = scenes.find((s) => frame >= s.start && frame < s.end) ?? scenes[0];
        const atmo = TEMP_ATMOSPHERE[(cur?.temp ?? "neutral") as Temp];
        return (
          <>
            <AbsoluteFill style={{ zIndex: 6, background: `radial-gradient(60% 50% at 50% 30%, ${atmo.fog} 0%, rgba(0,0,0,0) 70%)` }} />
            <Particles kind={atmo.kind} color={atmo.particle} />
          </>
        );
      })()}
      <Grain />
      <Scanlines intensity={0.16} />
      <Vignette alpha={0.6} />
      {scenes.some((s) => frame >= s.start && frame < s.end && s.effects.includes("gilt-frame")) && <GiltFrame />}

      {/* lower scrim for legibility */}
      <AbsoluteFill style={{ zIndex: 20, pointerEvents: "none",
        background: "linear-gradient(to top, rgba(0,0,0,0.74) 0%, rgba(0,0,0,0.32) 18%, rgba(0,0,0,0) 38%)" }} />

      {/* banner */}
      <div style={{ position: "absolute", top: 44, left: 56, zIndex: 24,
        opacity: interpolate(frame, [firstLineStart - 30, firstLineStart], [0, 0.9], { extrapolateLeft: "clamp", extrapolateRight: "clamp" }) }}>
        <div style={{ fontFamily: FONT_DISPLAY, fontWeight: 600, fontSize: 26, letterSpacing: "0.32em", color: "#d8bb66", textShadow: "0 2px 10px #000" }}>{bannerText}</div>
        <div style={{ fontFamily: FONT_LYRIC, fontStyle: "italic", fontSize: 24, color: "#a9b6c2", marginTop: 2, textShadow: "0 2px 10px #000" }}>Anti-Nativity</div>
      </div>

      {/* lyric lower third */}
      <AbsoluteFill style={{ zIndex: 22, pointerEvents: "none" }}>
        {ai !== -1 && (() => {
          const line = lines[ai];
          const start = lineStarts[ai];
          const nextStart = lineStarts[ai + 1] ?? durationInFrames;
          const visible = Math.min(nextStart - start, 7 * fps);
          const prog = frame - start;
          if (prog > visible) return null;
          const op = interpolate(prog, [0, 12, visible - 14, visible], [0, 1, 1, 0], { extrapolateLeft: "clamp", extrapolateRight: "clamp" });
          const c = VOICE_COLOR[line.voice];
          return (
            <div style={{ position: "absolute", left: 0, right: 0, bottom: 150, textAlign: "center", opacity: op, padding: "0 8%" }}>
              <div style={{ fontFamily: FONT_LYRIC, fontStyle: "italic", fontWeight: 600, fontSize: 52, lineHeight: 1.35, color: c.text,
                textShadow: `0 0 26px ${c.glow}, 0 3px 12px rgba(0,0,0,0.92)`, whiteSpace: "pre-line" }}>{line.text}</div>
            </div>
          );
        })()}
      </AbsoluteFill>

      {/* title card over the intro */}
      {frame < firstLineStart && (
        <AbsoluteFill style={{ zIndex: 26, justifyContent: "center", alignItems: "center", textAlign: "center",
          opacity: interpolate(frame, [16, 60], [0, 1], { extrapolateRight: "clamp" }) *
            interpolate(frame, [firstLineStart - 40, firstLineStart], [1, 0], { extrapolateLeft: "clamp", extrapolateRight: "clamp" }) }}>
          <div style={{ fontFamily: FONT_DISPLAY, fontWeight: 600, fontSize: 78, letterSpacing: "0.06em", color: "#e8d6a6", textShadow: "0 0 40px rgba(231,178,94,0.35), 0 4px 20px #000" }}>
            THE RECURSION OF<br />ASH AND LIGHTNING
          </div>
          <div style={{ fontFamily: FONT_LYRIC, fontStyle: "italic", fontSize: 34, color: "#9fb0c0", marginTop: 14, letterSpacing: "0.12em" }}>
            The Seventh Shadow — Anti-Nativity
          </div>
        </AbsoluteFill>
      )}

      {/* end card */}
      <AbsoluteFill style={{ zIndex: 26, justifyContent: "center", alignItems: "center", textAlign: "center",
        opacity: interpolate(frame, [durationInFrames - 110, durationInFrames - 70, durationInFrames - 20, durationInFrames], [0, 1, 1, 0.85], { extrapolateLeft: "clamp", extrapolateRight: "clamp" }) }}>
        <div style={{ fontFamily: FONT_DISPLAY, fontWeight: 600, fontSize: 40, letterSpacing: "0.3em", color: "#d8bb66" }}>THE SEVENTH SHADOW</div>
        <div style={{ fontFamily: FONT_LYRIC, fontSize: 26, letterSpacing: "0.3em", textTransform: "uppercase", color: "#9fb0c0", marginTop: 14 }}>anti-nativity.arda.tr</div>
      </AbsoluteFill>
    </AbsoluteFill>
  );
};
```
